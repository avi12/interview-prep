## How Israeli junior roles differ
| Topic | Finding |
|---|---|
| Degree | BSc CS/quant listed in ~60% of API postings; often "advantage". Hebrew job ads rarely hard-require it; big firms (NetApp, Check Point) do. (Search results found no army-unit requirement; unit 8200 / tech-unit pedigree is informal signal, unverified here.) |
| Experience | "Junior" often means 1-2y; students/interns (student jobs, part-time) are the real entry door. |
| Market 2026 | Headcount flat; layoffs concentrated in software (6.6%); planned hiring falling 7.2% to 5.9%; AI hits the new-hire stage hardest; 23% more hiring abroad ([Globes](https://en.globes.co.il/en/article-1001552032), [Ynet](https://www.ynetnews.com/tech-and-digital/article/skofzljxze), [Innovation Authority](https://innovationisrael.org.il/en/press_release/human-capital-in-tech-israel-2026/)). Calcalist: juniors judged on learning speed + AI-tool fluency ([article](https://calcalistech.com/ctechnews/article/338pvwopf)). |
| Language | Ads in English at product firms; Hebrew ads at agencies/enterprises; some roles demand fluent Hebrew. Interviews usually Hebrew with English tech terms. |
| Stacks | Product firms: Java, Node/TS, Python, Go; AWS dominant, GCP second; K8s/Kafka for backend. |
| Salary | Only AI-estimated (not employer-posted): entry analyst ~12-17k NIS/mo; mid backend 18-25k. Low confidence. |

## Typical interview loop (Glassdoor/Taro anecdotes, small samples)
1. Recruiter/HR phone screen (salary, army/degree, availability).
2. Home assignment or online test: Check Point = 3 LeetCode (easy-medium) via Codility-style; others a 1-3 day CRUD/React task (Bylith, Galil) followed by a walkthrough/presentation; Via = hard algorithmic take-home; Taboola = AI-assisted build task.
3. 1-2 technical rounds (~2h each): LeetCode-style, OOP/design patterns, data structures, project deep-dive, basic backend architecture. Check Point also Bash/memory questions.
4. Team lead / group manager meeting; for larger firms a full on-site day with 10+ candidates for 1-2 seats.
5. HR + references -> offer.
System design: light for juniors (architecture discussion on own take-home), full design rounds are senior.

## LeetCode level
Easy to medium. Arrays/strings/hash maps, linked lists, two pointers, basic trees/recursion; 2 easy + 1 medium is the modal take-home. Hard only for algorithm roles. Data analyst: SQL joins/window functions/aggregations, no LeetCode DP. AI: Python fluency + RAG/API design.
